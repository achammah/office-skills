Creative ideas for visual impact. Referenced from the main SKILL.md workflow.

Don't create boring slides. Every presentation is an opportunity for visual impact.

## Visual Details

**Geometric**: Diagonal dividers, asymmetric columns (30/70, 40/60), rotated text headers, overlapping shapes.
**Borders**: Thick single-side borders (10-20pt), corner brackets, L-shaped borders, underline accents.
**Typography**: Extreme size contrast (72pt vs 11pt), all-caps with wide spacing, monospace for data.
**Charts**: Monochrome with single accent, horizontal bars, dot plots, minimal/no gridlines.
**Layout**: Full-bleed images with overlays, sidebar columns (20-30%), modular grids.
**Backgrounds**: Solid color blocks (40-60%), split backgrounds (diagonal/vertical), edge-to-edge bands.

**Requirements**: Web-safe fonts only (Arial, Helvetica, Times New Roman, Georgia, Courier New, Verdana, Tahoma, Trebuchet MS, Impact). Clear visual hierarchy. Strong contrast.
